> 实验性音频驱动仅适用于运行 Windows 11 ARM64 的小米平板 5（`nabu`）。

本项目研究小米平板 5（nabu）的内置扬声器音频。设备配有四颗 Cirrus Logic CS35L41 功放。

## 使用要求

- 在平板上安装 Windows 需要**解锁引导程序（Bootloader）**。[nabu Windows 安装指南](https://github.com/erdilS/Port-Windows-11-Xiaomi-Pad-5/blob/main/guide/English/won-deployer-install-en.md)
- 加载使用测试签名的实验性音频驱动需要开启 **Windows 测试模式**（Test Mode，`TESTSIGNING`）。开启后需要重启 Windows。[微软测试模式文档](https://learn.microsoft.com/zh-cn/windows-hardware/drivers/install/the-testsigning-boot-configuration-option)
