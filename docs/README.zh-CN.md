# 小米平板 5 的 Windows 11 ARM64 扬声器

[English](../README.md) · [Русский](README.ru.md) · **简体中文**

本项目研究小米平板 5（nabu）的内置扬声器音频。设备配有四颗 Cirrus Logic CS35L41 功放。

## 项目状态 · 2026 年 11 月 23 日

| | 结果 |
| --- | --- |
| ✅ | Windows ARM64 版 CS35L41 驱动 4.17.27.8 已在测试平板的四颗功放上启动，并通过左右声道播放测试。 |
| ✅ | 使用 HyperOS 原厂扬声器保护和音乐配置，以及这台平板每颗功放的出厂校准数据。修复了 OTP 校准读取，并检查 DSP 写入错误。 |
| ✅ | 在相同输入信号和 Windows 音量下，内置麦克风测得部分测试频率比旧 Windows 驱动高 **6.6–11.7 dB**。 |
| ✅ | 启动跟踪记录了 Qualcomm DSP 固件和校准文件的成功打开。跟踪在播放测试之前达到了大小上限。 |
| ❌ | 重启后，Qualcomm DSP 上的系统级 Dolby 测试在打开 Windows 音频流时失败。使用原版 Dolby 库单独测试时，这台平板的 220 Hz 输出提升了 4.4–4.8 dB。 |
| ❌ | 仍需比较与 HyperOS 的最高音量，并在其他小米平板 5 上验证。 |

## 正在进行

- 跟踪从 Qualcomm DSP 启动到首次播放请求期间对 Dolby 注册文件和库的访问，定位音频流无法打开的原因。
- 对比 HyperOS 的音乐播放和最高音量，并验证其他设备的出厂校准。
