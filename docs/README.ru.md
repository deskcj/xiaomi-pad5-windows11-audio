> Экспериментальные аудиодрайверы предназначены только для Xiaomi Pad 5 (`nabu`) с Windows 11 ARM64.

Проект по звуку четырёх встроенных динамиков Xiaomi Pad 5 (nabu) с усилителями Cirrus Logic CS35L41.

## Требования

- **Разблокированный загрузчик** нужен для установки Windows на планшет. [Руководство по установке Windows на nabu](https://github.com/erdilS/Port-Windows-11-Xiaomi-Pad-5/blob/main/guide/English/won-deployer-install-en.md)
- **Тестовый режим Windows** (Test Mode, `TESTSIGNING`) нужен для экспериментального аудиодрайвера с тестовой подписью. После включения требуется перезапуск Windows. [Документация Microsoft о тестовом режиме](https://learn.microsoft.com/ru-ru/windows-hardware/drivers/install/the-testsigning-boot-configuration-option)

В повторном замере прирост на тестовых тонах составил **6,6–11,7 дБ**. В обоих прогонах использовались тот же планшет и встроенный микрофон, одинаковые входные уровни и громкость Windows. Для примера на 440 Гц входной уровень составил −36 dBFS.

В дополнительном тесте PCM16 / 48 кГц повышение входного уровня тона 440 Гц на 16 дБ дало прирост 15,8 дБ на каждом канале. В установленном драйвере действуют заводские настройки усиления, DRE и защиты динамиков HyperOS. [Дополнительные замеры](baseline.md#pcm16-level-response)

## Над чем работаю

- ❌ **Системный Dolby.** Контрольная схема со штатными модулями Qualcomm открывается. В пробе 1.0.2140.17 с предварительной загрузкой Dolby Windows снова вернула `0x8007045D` при открытии потока. Трасса подтвердила передачу таблицы путей к файлам. Загрузка модуля Dolby в DSP пока не подтверждена.
- ❌ **MiSound.** В проверенных конфигурациях Qualcomm DSP открывает схему, затем применение параметров эффекта завершается по тайм-ауту.
- ❌ **24-битное воспроизведение.** В проверенных конфигурациях воспроизвести 24-битный поток через встроенные динамики не удалось.
- ⏳ **Дальнейшие проверки.** Сравнить качество музыки и максимальную громкость с HyperOS, проверить заводскую калибровку на других Xiaomi Pad 5.
