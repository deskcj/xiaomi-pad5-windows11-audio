# Динамики Xiaomi Pad 5 в Windows 11 ARM64

Исследуем тихий или плоский звук встроенных динамиков Xiaomi Pad 5 (nabu). В звуковом тракте работают Qualcomm Aqstic и четыре усилителя Cirrus Logic CS35L41.

Windows видит четыре усилителя. Тихий тест WASAPI показал, что оба цифровых канала доходят до встроенного выхода в формате 48 кГц. Громкость и работа каждой из четырёх решёток требуют отдельной акустической проверки. Готового драйвера пока нет.

## Как проверить

В настройках звука выбери встроенные динамики Xiaomi Pad 5 и поставь на паузу остальное воспроизведение. В 64-битном PowerShell 7 запусти команду из папки проекта:

    ./tools/Measure-SpeakerBaseline.ps1 -PlayQuietTones

Прозвучит по одной секунде в левом и правом каналах с паузой. Пиковый уровень исходного сигнала −44,4 dBFS. Показания относятся к цифровому выходу Windows. Чтобы найти молчащую решётку, послушай каждый угол в одной ориентации планшета и запиши, какая решётка слышна на каждом тоне. Громкость Windows, ориентацию и расстояние до микрофона нужно записать для сравнения с Android.

[Замеры, драйверы и исходники](baseline.md)

Для относительного замера на самом планшете можно подключить встроенный фронтальный микрофон:

    ./tools/Measure-SpeakerBaseline.ps1 -PlayQuietTones -MeasureBuiltInMic

Сохраняются уровни тестовой частоты, без записи звука в файл. Чтобы сравнить две сборки Windows, оставь планшет в том же положении и используй те же настройки громкости и микрофона. Показания встроенного микрофона выражены в dBFS.
