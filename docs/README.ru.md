# Динамики Xiaomi Pad 5 в Windows 11 ARM64

[English](../README.md) · **Русский** · [简体中文](README.zh-CN.md)

Проект по звуку четырёх встроенных динамиков Xiaomi Pad 5 (nabu) с усилителями Cirrus Logic CS35L41.

## Статус · 23 ноября 2026

| | Результат |
| --- | --- |
| ✅ | Драйвер CS35L41 4.17.27.8 для Windows ARM64 запустился на всех четырёх усилителях тестового планшета. Проверено воспроизведение левого и правого каналов. |
| ✅ | Использованы оригинальная защита динамиков и музыкальные профили HyperOS, а также заводская калибровка каждого усилителя этого планшета. Исправлено чтение калибровки из OTP, добавлена проверка ошибок при программировании DSP. |
| ✅ | Встроенный микрофон зафиксировал прирост **6,6–11,7 дБ** на отдельных тестовых частотах по сравнению с прежним драйвером Windows. Входной сигнал и громкость Windows были одинаковыми. |
| ✅ | В трассе загрузки видно успешное открытие прошивки DSP Qualcomm и файлов калибровки. Трасса достигла лимита размера до пробы воспроизведения. |
| ❌ | Системный Dolby на Qualcomm DSP после перезагрузки не открыл аудиопоток Windows. Отдельный тест с оригинальной библиотекой Dolby дал прирост 4,4–4,8 дБ на 220 Гц на этом планшете. |
| ❌ | Сравнение максимальной громкости с HyperOS и проверка на других Xiaomi Pad 5 ещё впереди. |

## Над чем работаю

- Проследить открытие файла регистрации и библиотеки Dolby от запуска Qualcomm DSP до первого запроса на воспроизведение и найти причину сбоя.
- Сравнить музыку и максимальную громкость с HyperOS, проверить работу с заводской калибровкой других планшетов.

## Драйвер и исходники

Проверенная сборка 4.17.27.8 использует калибровку одного планшета. Публикация пакета Windows ARM64 и исходников для его сборки ждёт проверки загрузки заводской калибровки на других экземплярах. По ссылкам ниже доступны исходный Windows-драйвер и файлы платы Xiaomi.
