# Динамики Xiaomi Pad 5 в Windows 11 ARM64

Проект по звуку четырёх встроенных динамиков Xiaomi Pad 5 (nabu) с усилителями Cirrus Logic CS35L41.

Текущий драйвер Windows подаёт сигнал на усилители напрямую с аудиошины. Штатный Android использует DSP, защиту динамиков и калибровку усилителей. Прототип Windows ARM64 собран с той же прошивкой защиты и проходит проверку на планшете.
