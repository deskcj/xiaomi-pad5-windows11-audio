# Xiaomi Pad 5 speakers on Windows 11 ARM64

Driver research for the four internal Cirrus Logic CS35L41 amplifiers on Xiaomi Pad 5 (nabu).

The current Windows driver feeds the amplifier from its serial input. The stock Android path uses the CS35L41 DSP, speaker protection and per-amplifier calibration. The Windows ARM64 prototype uses matching protection firmware and awaits hardware validation.
